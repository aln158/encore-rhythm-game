# ENCORE · 返场 / 地下回响

作者：盛基伟。2D节奏割草网页游戏，v0.7.4。

打开网页后点击“重返舞台”。使用桌面浏览器与键盘，建议佩戴耳机。

- W：弹射水波；S：闪电贝斯；O：掀砖地震；K：追踪火球。
- 短音点按，长音按住；标记双音触发八种双人组合。
- Space：能量满后释放合奏；Esc：暂停；M：静音。
- 清理波次、招募乐手、选择装备，最终击败失拍指挥。

首次开始需下载四轨本地原创音乐，约46 MB；请等待下载和解码。四轨120秒立体声编曲v4，音乐与谱面时间保持一致。

本仓库只发布可运行静态网站与资源。Phaser、EventEmitter3及PVFX素材的许可证和来源见licenses目录。程序化原创音乐未使用第三方录音或艺人声音克隆。项目采用AI辅助编程、美术/音频制作与测试。

新版统一四元素、八种组合与实时大招；O 地震使用同色地砖抬升。元素试音台已改为角色与组合技教程，使用正式游戏渲染。
